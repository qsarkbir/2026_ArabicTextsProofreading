# OpenITI 校正アプリ

OpenITI のテキストを、元になった刊本のページ画像と並べて校正するローカルアプリです。ページ画像は Internet Archive（IIIF）から表示するか、手元の PDF をアップロードして使います。Claude にページ画像を読み取らせて、テキストとの食い違いを示すこともできます。

## 起動

Python 3.10 以上で動きます。Claude OCR を使わないなら追加のパッケージは要りません。

```bash
python -m proofreader
```

ブラウザで http://127.0.0.1:8765/ が開きます。`--port` でポートを、`--no-browser` でブラウザを開かない設定にできます。作業データは `projects/` に保存されます（環境変数 `PROOF_DATA` で変更可）。

### Claude OCR を使う場合

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

API キーは、リポジトリのルート（`README.md` と同じ場所）に `.env` ファイルを作って書いておきます。

```
ANTHROPIC_API_KEY=sk-ant-...
```

Claude OCR を使うときは、パッケージを入れた仮想環境の Python でアプリを起動します（`activate` してから `python -m proofreader` としても同じです）。

```bash
.venv\Scripts\python -m proofreader
```

`.env` は起動時に読み込まれ、PC 全体に設定した環境変数より優先されます。`.gitignore` で除外してあるので、コミットされることはありません。`.env` を使わずに、環境変数 `ANTHROPIC_API_KEY` を設定するか `ant auth login` でログインしておいてもかまいません。

読み取りは校正者がページを開いて「Claudeで読み取る」を押したときだけ行い、結果は `projects/<テキスト>/ocr/` に保存して再利用します。モデルはボタンの横で Opus 5.5（既定）・Sonnet 5.5・Haiku 5.5 から選べ、選んだモデルは次回も使われます。安いモデルほど読み誤りが増えることがあるので、気になるページは「読み直す」で別のモデルを試してください。選べるモデルは `proofreader/ocr.py` の `MODELS` で変えられます。

## 流れ

1. **テキストを読み込む**：OpenITI のバージョン URI（例：`1014IbnMaryamTilimsani.Bustan.Kraken22021817402301-ara1`）か GitHub の URL を入力します。手元の OpenITI 形式ファイルも使えます。ページ区切り（`PageV..P..`）のあるテキストが対象です。
2. **ページ画像を選ぶ**：メタデータ（yml）に Internet Archive へのリンクがあれば候補に出ます。なければ Internet Archive を検索するか、識別子を直接入れるか、PDF をアップロードします。
3. **ページの対応を合わせる**：テキストのページと同じ画像が出るまで番号を動かします。途中でずれたら、校正画面の ◀ ▶ でそのページ以降だけ直せます。
4. **校正**：左に画像、右にそのページのテキストが出ます。入力欄の内容が確定テキストで、自動で保存されます。Claude の読み取り結果がある場合は、食い違う語が黄色で示され、点線の枠をクリックするとその読みに置き換わります。

## 書き出し

書き出す前に最新の編集を保存します。保存に失敗した場合は、校正画面の「保存を再試行」を押してください。未保存の変更は画面に保持されますが、ブラウザの強制終了後には復元できません。

- **校正済みテキスト**：OpenITI 形式のまま。修正していないページは元のファイルと1文字も変わりません。
- **差分（.diff）**：元テキストとの unified diff。
- **注記・確認状況（CSV）**

## 比較の設定

「比較の設定」で、ハムザやター・マルブータの違い、句読点、語の続け書き・分かち書きの違いを無視するかどうかを切り替えられます。柱（ページ番号）と脚注は、既定では比較から外しています。

## 校正を続けるための操作

- **取り消す・やり直す**：手入力とOCR提案の採用を取り消せます。本文内では Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z も使えます。履歴は同じページを開いている間のみ保持します。
- **ページを探す**：校正後の本文・注記を検索し、未確認・修正あり・注記ありで絞り込めます。
- **資料・ページ対応**：上部のリンクから開きます。対応のプレビューは保存されず、変更して確定した場合だけ全体に適用し、途中ページの補正を解除します。資料自体を選び直した場合は、新しい資料を保存して対応を初期化します。

更新時の注意と変更履歴は [リリースノート](RELEASE_NOTES.md) を参照してください。

## 開発時の確認

```bash
python -m unittest discover -s tests -v
node --test tests/core.test.js
node --check proofreader/static/app.js
```

ブラウザ確認用に `python -m tests.preview_server` を実行すると、合成データだけを使うサーバーが `http://127.0.0.1:8772/` で起動します。最初の保存だけ意図的に失敗するため、再試行を確認できます。既存の `projects/` と有料OCRは使用しません。Ctrl+C で終了すると検証データも削除します。
