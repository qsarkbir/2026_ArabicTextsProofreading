# OpenITI 校正アプリ

OpenITI のテキストを、元になった刊本のページ画像と並べて校正するローカルアプリです。ページ画像は Internet Archive（IIIF）から表示するか、手元の PDF をアップロードして使います。Claude にページ画像を読み取らせて、テキストとの食い違いを示すこともできます。

## 起動

Python 3.10 以上で動きます。Claude OCR を使わないなら追加のパッケージは要りません。

```bash
python -m proofreader
```

ブラウザで http://127.0.0.1:8765/ が開きます。`--port` でポートを、`--no-browser` でブラウザを開かない設定にできます。作業データは `projects/` に保存されます（環境変数 `PROOF_DATA` で変更可）。

### Claude OCR を使う場合

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

API キーは環境変数 `ANTHROPIC_API_KEY` に設定するか、`ant auth login` でログインしておきます。読み取りは校正者がページを開いて「Claudeで読み取る」を押したときだけ行い、結果は `projects/<テキスト>/ocr/` に保存して再利用します。モデルは `claude-opus-5-5` です（`proofreader/ocr.py`）。

## 流れ

1. **テキストを読み込む**：OpenITI のバージョン URI（例：`1014IbnMaryamTilimsani.Bustan.Kraken22021817402301-ara1`）か GitHub の URL を入力します。手元の OpenITI 形式ファイルも使えます。ページ区切り（`PageV..P..`）のあるテキストが対象です。
2. **ページ画像を選ぶ**：メタデータ（yml）に Internet Archive へのリンクがあれば候補に出ます。なければ Internet Archive を検索するか、識別子を直接入れるか、PDF をアップロードします。
3. **ページの対応を合わせる**：テキストのページと同じ画像が出るまで番号を動かします。途中でずれたら、校正画面の ◀ ▶ でそのページ以降だけ直せます。
4. **校正**：左に画像、右にそのページのテキストが出ます。入力欄の内容が確定テキストで、自動で保存されます。Claude の読み取り結果がある場合は、食い違う語が黄色で示され、点線の枠をクリックするとその読みに置き換わります。

## 書き出し

- **校正済みテキスト**：OpenITI 形式のまま。修正していないページは元のファイルと1文字も変わりません。
- **差分（.diff）**：元テキストとの unified diff。
- **注記・確認状況（CSV）**

## 比較の設定

「比較の設定」で、ハムザやター・マルブータの違い、句読点、語の続け書き・分かち書きの違いを無視するかどうかを切り替えられます。柱（ページ番号）と脚注は、既定では比較から外しています。
